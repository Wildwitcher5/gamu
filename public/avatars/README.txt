Avatars folder
==============

Place player avatar images here. Supported formats: PNG, JPG, WebP.

Subfolders:
  pro/       — "for" / ally-side avatars (warm/heroic style)
  against/   — enemy-side avatars (dark/menacing style)
  neutral/   — neutral / misc avatars

Naming convention: av1.png, av2.png, ... av8.png
Recommended size: 128×128 px (displayed at 36–40 px in-game).
